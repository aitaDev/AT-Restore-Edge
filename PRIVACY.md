# Privacy Policy for AT-Restore

**Effective date:** September 9, 2026

AT-Restore stores only the text drafts and text-field selectors that the user explicitly chooses to protect. This data is stored locally in the browser using the extension storage API.

AT-Restore does not collect, transmit, sell, share, or use personal data for advertising, analytics, profiling, or any purpose outside draft recovery. No saved draft content is sent to the developer or to third parties.

The extension requests access to web pages so it can identify the text field selected through the browser context menu, save changes to that field, and restore the saved draft on that page. It uses the context menu permission to provide the “Protect this text box” and “Recover” commands.

Users can remove a protected field from the extension popup. Uninstalling the extension removes its locally stored data according to the browser’s extension-storage behavior.

Questions may be submitted through the public GitHub repository: https://github.com/aitaDev/AT-Restore/issues
